# 认识这个世界

这是一个用通俗叙事认识世界的项目。我们从六个彼此关联的方面出发，观察我们身处的世界从何而来、如何运转，以及可能走向何方。

项目网站：[认识这个世界](https://luskyle.github.io/the-world/)

## 六个主题

- **天文（Astronomy）**：仰望星空，了解宇宙、恒星、行星，以及地球在其中的位置。
  - [01｜没有望远镜，他们凭什么读懂星空？](astronomy/01-没有望远镜，他们凭什么读懂星空.md)
  - [02｜月亮每晚都在“迟到”，古人怎么用它造日历？](astronomy/02-月亮每晚都在迟到，古人怎么用它造日历.md)
  - [03｜火星没有倒车，为什么看起来在后退？](astronomy/03-火星没有倒车，为什么看起来在后退.md)
  - [04｜日食能算出来吗？古人抓住了什么规律？](astronomy/04-日食能算出来吗，古人抓住了什么规律.md)
  - [05｜一根木棍量出地球：两千年前的几何奇迹](astronomy/05-一根木棍量出地球，两千年前的几何奇迹.md)
  - [06｜千年前的“客星”档案，如何揭开一场恒星爆炸？](astronomy/06-千年前的客星档案，如何揭开一场恒星爆炸.md)
- **环境（Environment）**：关注地球的自然环境、气候、资源，以及人与自然的相处方式。
- **生命（Life）**：探索生命的起源与多样性，认识人类和其他生物如何生活、演化。
- **文化（Culture）**：从语言、历史、艺术与日常生活中，理解不同的人群如何认识世界。
- **科技（Technology）**：了解工具与科学如何改变生活，以及技术带来的机会和挑战。
- **未来（Future）**：思考世界可能发生的变化，以及我们可以共同做出的选择。

## 写作方式

尽量从具体的问题和熟悉的生活经验讲起，少用难懂的术语；遇到必要的概念，也会用简单的例子解释清楚。六个主题不是孤立的分类，而是理解同一个世界的不同入口。

项目文章的详细创作规范见 [AI 文章创作指引](.github/instructions/editorial-writing.instructions.md)。
